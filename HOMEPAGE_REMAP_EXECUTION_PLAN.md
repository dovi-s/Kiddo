# Homepage Remap Execution Plan

## Purpose

This document turns the master website brief into an execution plan against the
current homepage implementation.

It answers:

- what stays
- what gets cut
- what gets merged
- what gets moved off the homepage
- what new homepage structure should replace the current one

This is not a generic critique. It is the bridge from `Home.tsx` as it exists
today to the sharper, singular homepage the company actually needs.

---

## The One Rule

The homepage should make one truth land:

**The best gift for a child is one that lasts.**

Anything that does not directly help land that truth should be either:

- compressed
- moved deeper
- or removed from the homepage entirely

---

## Current Homepage: What It Is Doing

The current homepage contains many strong ideas:

- hero thesis
- trust counter
- Memory Book emotional section
- product bento
- desktop dashboard showcase
- "well-intentioned gifts disappear" framing
- 3-step gift/fund flow
- gift demo
- Kid View section
- age-18 transition section
- trust/security section
- locked refusals
- cost-of-waiting section
- final CTA

The problem is not that any one of these is bad.

The problem is that too many of them are trying to be a major beat. The page
contains several strong centerpieces when it should contain one clear narrative.

---

## New Homepage Structure

Replace the current homepage shape with this order:

1. Hero
2. Three proof pillars
3. Memory Book moat
4. Gift flow
5. Trust block
6. Age-18 payoff
7. Final CTA

Everything else should either move off the homepage or become subordinate
support inside one of those sections.

---

## Section-by-Section Remap

## 1. Hero

### Keep

- The core emotional direction of the current hero
- The "gift that lasts" framing
- The direct CTA posture
- The premium, calm register

### Change

- Reduce the number of simultaneous conceptual jobs the hero is doing
- Remove any supporting material that belongs below the fold
- Make the hero visual carry more of the burden

### New target

The hero should contain only:

- one headline
- one subhead
- one primary CTA
- one secondary CTA
- one trust line
- one flagship visual

### Notes

The hero should not preview the entire product architecture. It should make the
product legible and emotionally desirable immediately.

---

## 2. Three Proof Pillars

### Current homepage source material

The current page has this content spread across:

- hero supporting proof
- bento tile explanations
- gifting simplicity statements
- dashboard/product sections

### Action

Compress all of that into three short proof pillars directly under the hero:

- No account needed to give
- Every gift can grow
- The story stays with it

### Cut

- long supporting proof paragraphs at this stage
- too many second-order feature claims

### Why

Visitors need immediate proof, not a product tour.

---

## 3. Memory Book Moat

### Keep

- The current homepage's best emotional material around Memory Book
- The "who showed up for them" framing
- The sense that this is what makes Kiddo unlike a plain brokerage

### Merge from current sections

Merge relevant energy from:

- the current Memory Book section
- parts of the Kid View emotional framing
- parts of the age-18 emotional framing

### Cut

- too much explanatory text about visibility tiers or system behavior on home
- secondary Memory Book mechanics

### New target

This should become the emotional center of the page.

It should answer:

**Why does this matter beyond the money?**

### Visual direction

This section deserves one of the flagship assets.

---

## 4. Gift Flow

### Keep

- The existing product truth that gifting is very simple
- The no-account wedge
- The "share a link, family gives" logic

### Compress from current sections

Use the strongest parts of:

- the 3-step flow section
- the gift demo section
- gifting copy in the hero and product tiles

### Cut

- duplicated explanations of gifting across the page
- too many "for grandma" / "for the family" support paragraphs
- anything that turns this into a full operational walkthrough

### New target

The homepage should show:

1. Start a fund
2. Share the link
3. Family gives

Nothing more is needed at this stage.

### Visual direction

Use either:

- one very clean product still
- or one short loop showing how easy giving is

But not a large, complex demo sequence here.

---

## 5. Trust Block

### Keep

- The current security/trust truths
- The refusal posture
- The clear "not public / not searchable / transparent fees" messaging

### Merge from current sections

Merge together:

- public trust lines from the hero
- the trust/security section
- the strongest pieces of LockedRefusalsPanel

### Move out

Move deeper:

- detailed brokerage/custody nuance
- legal detail
- repeated trust explanation
- long trust prose

That belongs on the Security page and FAQ.

### New target

The trust block should be short, definitive, and calm.

It should say:

- private, not searchable
- no platform fee on gifts
- fees shown before checkout
- real custody structure when live
- the money belongs to the child

### Important

Trust should feel more authoritative and less defensive than it does now.

---

## 6. Age-18 Payoff

### Keep

- The emotional truth that the product matters because of the handoff
- The "money and story transfer together" framing

### Merge from current sections

Pull the best material from:

- the current age-18 section
- the current Memory Book future-facing copy
- any strong handoff lines from About/Age18 surfaces if later needed

### Cut

- legal/mechanical detail on the homepage
- too much "here is how the transition works"

### New target

This should answer:

**What makes this fundamentally bigger than a normal child account?**

### Visual direction

This should be one of the four flagship assets.

It should feel like inheritance, not admin.

---

## 7. Final CTA

### Keep

- The existing strong "start now" posture
- The calm reassurance that it is free to start

### Cut

- too much final-stage explanation
- too many secondary links competing for exit attention

### New target

One clean close:

- Start your child's fund
- Free to start
- Takes about 2 minutes

Two buttons max.

---

## What Leaves the Homepage Entirely

These can still exist on the site, but should no longer occupy major homepage
real estate:

- deep strategy/mix explanation
- large portions of pricing nuance
- FAFSA and 529 nuance
- compare logic
- trust edge-case depth
- operational FAQ logic
- multiple demo surfaces competing with one another
- too many feature tiles
- too much educational framing

The homepage should not function as:

- product tour
- FAQ
- pricing page
- security page
- education center
- compare page

It should function as:

**the front door**

---

## What Stays Elsewhere

These should remain strong, but on their correct pages:

- pricing architecture on Pricing
- trust depth on Security
- edge cases in FAQ
- search capture in Compare/Blog/Tools
- deeper product narrative in How It Works

The redesign is not about deleting intelligence. It is about placing it where
it belongs.

---

## Homepage Visual Strategy

The homepage should use only four major visual moments:

1. Hero asset
2. Memory Book asset
3. Gift flow asset
4. Age-18 asset

Everything else should either:

- support those assets quietly
- or disappear

The current page has multiple strong visual candidates, but too many of them
have equal status. The redesign should create a hierarchy of images the same
way it creates a hierarchy of ideas.

---

## Homepage Motion Strategy

The homepage should not feel animated. It should feel alive.

### Use motion for

- hero entrance
- one elegant reveal in the emotional center
- CTA tactility
- one or two product proof moments

### Reduce or remove

- repetitive section fade-ins as a default language
- multiple visually noisy demos
- motion that explains instead of clarifies

### Scroll rhythm

The page should feel like:

1. immediate comprehension
2. quick proof
3. emotional deepening
4. trust stabilization
5. action

The current homepage often feels like a sequence of many thoughtfully-built
modules. The new homepage should feel like one directed experience.

---

## The Actual Keep / Merge / Cut Summary

### Keep strongly

- the emotional core
- no-account gifting
- Memory Book
- age-18 handoff truth
- refusal/trust posture
- transparent fee integrity
- real product screenshots and proof

### Merge

- multiple gifting explanations into one gift-flow section
- multiple trust explanations into one trust block
- multiple future-oriented emotional beats into one age-18 payoff

### Cut or move

- extra feature density
- repeated proof claims
- deep mechanics
- long justifications
- sections that are true but non-load-bearing for first conversion

---

## Recommended Next Build Order

1. Rewrite homepage section order in code
2. Replace current hero with the new hero structure
3. Collapse scattered proof into three proof pillars
4. Promote Memory Book into the emotional center
5. Compress gifting into one decisive flow block
6. Build one calmer trust block
7. Rewrite the age-18 section as payoff, not explanation
8. Replace current closing area with a shorter CTA close
9. After structure is right, refine visuals and motion

Do not reverse that order.

Do not polish the current sprawl into a prettier sprawl.

---

## Final Standard

The new homepage should feel:

- more singular
- more legible
- more emotionally forceful
- more trustworthy
- more memorable
- less crowded
- less eager to explain
- more inevitable

If it merely feels cleaner, it is not enough.

If it feels like a category-defining company, it worked.
