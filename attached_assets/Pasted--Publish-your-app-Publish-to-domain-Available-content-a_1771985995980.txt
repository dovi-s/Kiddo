What is a live Stripe account?
A Stripe live account is one that has been activated and verified using your business details.
How do I find my live keys?
1. Navigate to your live account. You can find a list of all your accounts in your Stripe dashboard by clicking on the drop down in the top left.
2. From the bottom left, click "Developers" > "API Keys"
3. Reveal your live keys or create new ones. For step-by-step instructions on creating new keys, see Create a secret API key.

T002: Fix Kid View Growth Calculation
Blocked By: []
Details:
KidView.tsx accesses fund?.totalContributed and fund?.contributions but the /api/public/funds/:id/overview endpoint doesn't return these fields. The code falls back to using balance, making growth always show 0%.
Add totalContributed to the public overview endpoint by summing gift netAmounts for the fund.
Also handle negative growth (market losses) gracefully.
Files: server/routes.ts, client/src/pages/KidView.tsx
Acceptance: Kid View shows accurate growth percentage based on actual contributions vs current balance
T003: Add Admin Role Authorization
Blocked By: []
Details:
Admin endpoints (/api/admin/*) only check isAuthenticated. Any logged-in user can see all admin data. This is a critical security issue.
Add isAdmin field to users table (boolean, default false), or use email-based allowlist.
Add isAdmin middleware that checks the field.
Apply to all 5 admin endpoints.
Hide the Admin nav link for non-admin users in sidebar/nav.
Files: shared/models/auth.ts, server/routes.ts, client/src/components/layout/DesktopSidebar.tsx, client/src/components/layout/MobileNav.tsx
Acceptance: Only admin users can access admin endpoints and see admin nav

T005: Pass Execution Model to Stripe Checkout
Blocked By: []
Details:
GiftCheckout captures executionModel and selectedTicker in frontend state but doesn't send them to the /api/stripe/checkout/gift endpoint. They're captured in the gift record via webhook metadata but the values are never passed.
Add executionModel and selectedTicker to the checkout request body and include them in Stripe session metadata.
Files: client/src/pages/GiftCheckout.tsx, server/routes.ts
Acceptance: Gift records have correct executionModel and selectedTicker values
T006: Fix Event Boost Tracking
Blocked By: []
Details:
Events have hasEventPass and eventPassPurchasedAt fields but these are never properly checked or used consistently across the app.
The webhook handler handleEventPassPurchase should set hasEventPass=true and eventPassPurchasedAt=now() on the target event. Verify this works.
The fee calculation should check the event's hasEventPass flag (not just user subscription) to determine if the $2 Kora fee is waived.
Files: server/webhookHandlers.ts, server/stripeService.ts, server/routes.ts
Acceptance: Event Boost purchase correctly marks the event, and gifts to that event have $0 Kora fee
